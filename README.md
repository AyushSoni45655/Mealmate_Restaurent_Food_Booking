# 🍽️ MealMate

MealMate is a full-stack restaurant food booking application that lets users browse restaurants, explore menus, and place food orders or table bookings with ease. It is built on the MERN stack with a clean, responsive UI.

## ✨ Features

- Browse restaurants and view detailed menus
- Search and filter food items
- Book food orders or tables online
- User authentication and account management
- Order and booking history
- Fully responsive design for mobile and desktop

## 🛠️ Tech Stack

**Frontend:** React, Tailwind CSS
**Backend:** Node.js, Express.js
**Database:** MongoDB, Mongoose

## 🚀 Getting Started

1. Clone the repository
   git clone https://github.com/your-username/mealmate.git
   cd mealmate

2. Install dependencies
   cd Frontend && npm install
   cd Backend && npm install

3. Create a `.env` file in the server folder
   MONGO_URI=your_mongodb_connection_string
   JWT_SECRET=your_secret_key
   PORT=5000

4. Run the app
   # Backend
   cd Backend && npm run dev

   # Frontend
   cd Frontend && npm run dev
